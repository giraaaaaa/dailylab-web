# 접히는 도시 재구성

2026-10-21. `feat/lab-specimens` 작업 트리. 이번 범위는 도시이며 운영 배포는 하지 않았다.

## 왜 교체했나

첫 개편은 ‘구조적으로 접히는 기구’를 해결하는 데 집중했다. 사용자가 요구한 압도적인 공간, 유려한 움직임, 한눈에 드러나는 기술적 완성도를 작은 팝업 모형으로 축소했다. 기하가 성립하는 것과 장면이 멋진 것을 혼동한 판단이었다. 이번에는 거리에서 시작해 도시 전체가 머리 위를 덮는 한 장면을 중심으로 재구성했다.

실험실의 기존 흑백·코발트 한 군데 규칙을 유지했다. 접힘을 설명하는 수치 HUD를 없애고 공간과 움직임이 먼저 보이게 했다. 타일·막·방의 추가 재설계는 이번 결과를 본 뒤 진행한다.

## 구현

- 지면 가까운 원근 시점. 도로, 인도·연석·줄눈, 횡단보도, 가로등, 차량, 옥상 설비와 먼 스카이라인을 배치했다.
- 12개 구역 중 앞의 4개를 고정하고 뒤의 8개가 먼 쪽부터 시차를 두고 접힌다. 각 구역의 도로·건물·시설물은 같은 강체 좌표를 사용한다. 인접 지면의 끝점은 항상 연결된다.
- 버튼은 약 6초에 걸친 가속·감속과 관절별 감쇠를 사용한다. 위아래 드래그, 휠, 방향키, Home/End로 중간 상태와 역방향을 직접 조절한다. 자동 시연은 접기·머무르기·펼치기·대기를 반복한다.
- 콘크리트와 창문의 절차적 재질, 돌출된 외벽 띠와 옥상 장비, 실시간 그림자, 거리 안개, 절제된 색 보정·비네트·입자를 적용했다. 건물과 도로 시설물은 재질별 인스턴싱으로 묶었다.
- 움직일 때만 저음 마찰 루프가 커지고 멈추면 잦아든다. 로컬 생성 오디오 3초를 0.36초 겹쳐 2.64초 루프로 가공하고 AAC로 넣었다. 기본 무음이며 기존 공통 소리 설정을 따른다. 생성 원본 PCM 피크 0.510, RMS 0.082, 경계 샘플 차이 0.00046을 확인했다. 청감 검증은 하지 못했다.
- 보이지 않거나 정지하면 렌더 루프가 멈춘다. 동작 줄이기에서는 잔여 운동 없이 요청한 접힘 형태로 바뀐다. 화면 크기에 따라 시야각과 그림자 해상도·샘플 수를 제한한다.

## 확인

- 단위 테스트 20개 통과. 새 도시 테스트는 지면 경계 연결·강체 프레임, 앞쪽 고정·뒤쪽 순차 접힘, 시간 간격별 반복 역전·안정화, 동작 줄이기 상태를 포함한다. 폐기한 팝업 테스트는 제거했다.
- 프로덕션 빌드 성공. 기존 큰 Three.js 청크와 외부 공용 폰트 경로 안내는 남아 있다.
- 프로덕션 미리보기의 1280×720과 390×844에서 거리·접힌 구도·조작 배치를 확인했다. 드래그 역전, 키보드 Home/End, 접기 버튼과 자동 왕복을 확인했다. 새 탭의 콘솔 오류는 없었다.
- 실제 장면을 CUA 스크린샷으로 기록하고 프레임별 시각 확인 후 목록용 15.6초 영상과 포스터를 교체했다. 캡처 빈도는 약 13fps이며 영상 컨테이너는 30fps다. 이것을 실시간 렌더링 성능 측정으로 보지 않는다.
- 화면 증거: `city-rebuild-preview/`. 물리적인 휴대폰의 FPS·발열·터치 지연은 측정하지 않았다.

## 남는 한계

도시가 연속 곡면처럼 보이지만 실제로는 18m 구역별 경첩이다. 재질과 건물은 절차적 모형이며 영화용 도시 자산의 디테일 수준은 아니다. 보행·교통 시뮬레이션과 자유 카메라 이동은 없다. 건물 전부의 충돌을 푸는 범용 물리 엔진은 사용하지 않았다. 이번 결과는 새 공간 연출을 사용자가 판단할 수 있는 구현이며, 다른 작품보다 우수하다는 평가를 단위 테스트나 빌드 성공으로 대신하지 않는다.
